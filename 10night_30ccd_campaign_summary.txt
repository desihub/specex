10-night x 30-CCD campaign: Python (GPU) vs C++ (CPU) timing + correctness
============================================================================
Source: 2026-08-11/12 session, porting-notes.md "10-night campaign" section.
Method: real production preproc/shifted-PSF files staged into a private
redux tree (testing/stage_preproc.py) so both pipelines run the exact same,
complete, genuine production input via desi_proc's real -n101 scheduling
(C++) or run_night.py --backend python (Python) -- true apples-to-apples,
single CPU node (C++) vs single 4-GPU node (Python).
Correctness = XTRACE/YTRACE RMS difference (px) between the two pipelines'
independently-fit output, Legendre trace polynomials evaluated on a
100-point wavelength grid, broken fibers excluded, averaged over all
non-broken fibers in a camera then averaged over all 30 cameras/night.
Correctness columns regenerated directly from the campaign's own saved FITS
output for this table (not retyped from memory) -- reproduces the
previously-recorded aggregate (mean xrms 0.0277px, mean yrms 0.0163px,
night-mean ranges [0.0234,0.0308]/[0.0145,0.0200]) to 4 decimal places.
Timing columns for 20260316 and 20260401 recovered from a Slack post
(the original run logs for those two nights had been overwritten); all
other timing figures are from the original run logs directly.

Output locations on disk (Perlmutter /pscratch, confirmed still present):
  Python (GPU) fit-psf output, all 10 nights, one shared directory
  (files distinguished by expid, so no collisions across nights):
    /pscratch/sd/c/cdwarner/specex/cpptest/redux/cdwarner/
      fit-psf-<camera>-<expid>.fits   e.g. fit-psf-b0-00344649.fits

  C++ (CPU) fit-psf output, one subdirectory per night/expid (real
  desi_proc redux tree layout, staged via testing/stage_preproc.py):
    /pscratch/sd/c/cdwarner/specex/cpptest/desiproc2/<night>_<expid>/redux/cdwarner/exposures/<night>/<expid>/
      fit-psf-<camera>-<expid>.fits   e.g.
      /pscratch/sd/c/cdwarner/specex/cpptest/desiproc2/20260401_00344649/redux/cdwarner/exposures/20260401/00344649/fit-psf-b0-00344649.fits

  Both are on /pscratch, which is purged on Perlmutter's normal scratch
  retention policy (unused files eventually deleted) -- not a permanent
  archive location.

Headline: C++ averages ~8% faster than Python in this single-node
(4x A100 GPU vs single CPU node), same-real-input comparison. Correctness
is stable across all 10 nights and matches the project's established
~0.02-0.03px band; two nights carry a known, root-caused, non-systematic
elevated yrms (20241021 z6/fiber 343: isolated single-fiber issue, camera
yrms 0.118px vs its own ~0.019px once excluded; 20220120 r9/spectrograph 9:
amplified but bounded bundle-boundary-fiber weakness, not a new failure
mode) -- see porting-notes.md 2026-08-11/12 entry, "Hard case 1"/"Hard case 2".
